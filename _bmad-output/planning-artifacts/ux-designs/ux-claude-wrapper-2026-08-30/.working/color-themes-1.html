Claude Wrapper — Color Theme Explorations

Five directions for the DAG canvas that visualizes agent ("flight") execution. Brief was explicit: colorful, not a dark-terminal aesthetic. Each variation shows its full token set plus a live mock — a small agent DAG for the task "add OAuth2 login with JWT" and a Pre-Flight Permission checklist — in both a light and a dark rendition, so shape/typography choices (not just hue) can be compared side by side.
